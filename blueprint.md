# Blueprint

## Overview

This project is an immersive VR tour experience built with A-Frame. It allows users to navigate between different 360-degree scenes, interact with hotspots, and includes an editor mode for creating and modifying tours.

## Styles and Designs

*   **Aesthetic:** Clean, modern, and playful with a focus on interactive elements.
*   **Layout:** Centered and clean, with a focus on typography and negative space.
*   **Fonts:** Poppins for a clean and modern look.
*   **Colors:** An off-white background with blue text and vibrant accents.
    *   `--background-color: #f4f7fc`
    *   `--text-color: #0a2540`
    *   `--primary-color: #0077ff`
    *   `--secondary-color: #6772e5`
    *   `--accent-color: #32d7a0`
*   **Animations:**
    *   **Interactive Bubbles:** A physics-based bubble animation where a special bubble follows the cursor and collides with other bubbles on the screen.

## Features

*   **VR Experience:** An immersive VR experience using A-Frame.
*   **Scene Navigation:** Users can navigate between different 360-degree scenes.
*   **Hotspots:** Interactive hotspots provide information and allow for navigation.
*   **Editor Mode:** A built-in editor for creating and modifying tours.
*   **Interactive Cursor:** A playful cursor effect with physics-based bubbles that realistically bounce off each other, with the cursor's speed affecting the collision's impact.
